# PeakSirius

A simple PeakSirius Suite for Distributed Query Optimization.

PeakSirius is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- typescript

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/PeakSirius.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure PeakSirius, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
